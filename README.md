# STKFormer: Data Sources

A concise data-source guide for **STKFormer**, a multi-source framework for long-term PM2.5 forecasting.

The study described in the manuscript covers **Beijing, Shanghai, Guangzhou, and Tangshan, China**, using 78 air-quality monitoring stations from 2021 to 2023. It combines air-quality observations, meteorological variables, industrial POI-derived features, and MODIS MAIAC aerosol optical depth (AOD) context.

## Official data access links

- **Air quality (PM2.5, PM10, NO2, CO, O3, SO2):** [China National Environmental Monitoring Centre (CNEMC)](https://www.cnemc.cn/)
- **Meteorological observations:** [China Meteorological Data Service / CMA portal](https://k.data.cma.cn/mekb/?r=site%2Findexdata)
- **Industrial points of interest (POIs):** [Amap Open Platform](https://lbs.amap.com/)
- **MODIS MAIAC AOD:** [NASA LAADS MCD19A2 product page](https://ladsweb.modaps.eosdis.nasa.gov/missions-and-measurements/products/MCD19A2)

## Important note

This repository provides source links and a brief description; it **does not host the raw experimental dataset**. Some data may require registration or authorization, and provider terms may restrict redistribution. These links are official access points, not a guarantee of unrestricted bulk download. Please confirm the exact dataset/product versions against the original acquisition records and follow each provider's terms.
